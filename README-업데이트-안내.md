# Minseo Kim Research Notes — 확장 편집기 (v2)

홈페이지: https://minsonearth.github.io/
관리자 편집: https://minsonearth.github.io/?edit=1
CV 편집: https://minsonearth.github.io/cv.html?edit=1

## 배포 (기존 저장소 삭제 필요 없음)

1. 다운로드한 ZIP 파일을 **압축 해제**하세요.
2. GitHub `MinsOnEarth/minsonearth.github.io` 저장소에서 **Code → Add file → Upload files**를 클릭하세요.
3. 압축 푼 **폴더 안의 파일들만** 선택해 업로드하세요. `index.html`, `content.json`, `editor.js` 등이 최상위(root) 위치에 있어야 합니다.
4. **Commit changes**를 클릭하고 배포가 완료되면 사이트에서 `Ctrl + Shift + R`을 누르세요.
5. `?edit=1`로 접속해 기존 GitHub 토큰(유효한 경우)으로 연결하세요. 별도 새 토큰 발급은 필요하지 않습니다.

⚠ **이미 웹사이트에서 글을 수정한 적이 있다면** GitHub의 기존 `content.json`을 먼저 다운로드해 백업하세요. ZIP의 `content.json`으로 덮어쓰면 과거 편집 내용이 초기값으로 바뀔 수 있습니다. 안전하게 유지하려면 기존 `content.json`은 그대로 두고 나머지 파일만 업로드해도 됩니다(신규 문구는 각 HTML 파일의 기본값으로 표시됩니다). 신규 대화 문구/링크는 관리자에서 설정할 수 있습니다.

## 편집 방법

- **글**: 책 본문의 점선 표시 텍스트를 클릭해 수정 후 게시.
- **모든 문구**: 기존에 수정 안 되던 목차, 버튼 안내문구, 작은 캡션, 표지 텍스트 등을 검색해 선택하고 **이 문구 수정 적용 → 변경 내용 게시하기**.
- **대화 예시**: Chapter 02의 AI/인간 의사와 Cue 유무별 상담 텍스트 편집.
- **연구실적**: 추가 프로젝트·논문을 등록하고 수정/삭제. 본래 디자인에 고정된 기존 예시 항목은 문구 수정은 가능하지만 통째로 삭제하는 기능은 별도 개발이 필요합니다.
- **사진·CV**: 프로필 사진과 공개 CV PDF 파일 업로드.
- **CV 웹페이지**: `cv.html?edit=1`에서 학력, 연구경력 등의 문장을 바로 편집하거나 '모든 문구' 탭을 이용하세요. 별도로 토큰 연결해야 할 수 있습니다.

변경 사항은 GitHub의 `content.json`에 저장되고, GitHub Pages 배포가 완료되면 방문자 화면에 반영됩니다.

## 편집 가능한 범위와 아직 안 되는 것

홈페이지 본문의 대다수 정적 텍스트, 메뉴명, 안내문구, 논문 및 프로젝트 데이터, 2×2 상담 예시, CV 요약문과 파일 업로드가 지원됩니다. 단, 자유롭게 새로운 챕터를 만들거나, 페이지 순서를 변경하거나, 요소를 드래그로 배치하거나, 서체·색상·3D 애니메이션을 디자인 툴처럼 편집하는 기능은 아닙니다. 그런 작업은 HTML/CSS/JS 수정이 필요합니다.

토큰은 비밀번호처럼 관리하고 GitHub에 업로드하거나 공유하지 마세요. 방문자는 `?edit=1` 화면에 들어올 수 있어도 게시에는 쓰기 권한이 있는 GitHub 토큰이 필요합니다.
